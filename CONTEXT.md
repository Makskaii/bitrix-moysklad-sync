# Bitrix24–МойСклад

Общий язык для синхронизации записей двух систем.

## Документы

**Сделка**:
Документ CRM в Bitrix24, соответствующий заказу покупателя в МойСклад.

**Заказ покупателя**:
Документ продажи в МойСклад, соответствующий сделке в Bitrix24.
_Avoid_: Сделка МойСклад

**Подтверждённая пара документов**:
Сделка и заказ покупателя, связь которых сохранена по собственным идентификаторам обеих систем. Сходство названий или товарного состава само по себе не подтверждает пару.

**Первичная карта клиентов**:
Сохранённые пары компаний/контактов Bitrix24 с контрагентами/контактными лицами МойСклад. Карта хранит нативные ID обеих сторон; новая пара строится по точному UUID-полю Bitrix24, совпадающему с ID подходящего объекта МС, только при уникальном результате. Ранее подтверждённые пары сохраняются. Карта охватывает записи любого возраста и не запускает обмен историческими документами.

**Runtime-поиск клиента**:
Дополнительный поиск целевой клиентской записи при обработке нового документа, если сохранённой пары нет. Для компаний и контактов используются отдельные признаки и порядок выбора из `requirements.md`; этот поиск не меняет правила первичной карты.

**Несопоставленная клиентская запись**:
Запись компании/контакта, для которой первичная карта не сохранила однозначную пару. Статус и причина хранятся в нашем сервисе и сами по себе не означают дубль или удаление записи.

**Исторический документ**:
Сделка, заказ покупателя или счёт, созданные до границы рабочего запуска сервиса. Такой документ не сопоставляется и не синхронизируется, в том числе при последующих изменениях.
